# 📚 AI Study Planner

A productivity-focused web application designed to help students organize their study sessions efficiently.

## 🚀 Features

- Intelligent AI-powered scheduling
- Difficulty-based time allocation
- Custom mnemonics generation using Groq (Llama-3)
- Deep-dive explanations for better retention
- Dynamic responsive UI

## 🛠 Tech Stack

- Python (Flask)
- Groq Cloud API (Llama-3)
- HTML5
- CSS3
- JavaScript

## ⚙️ Installation

1. Clone the repository
2. Create virtual environment
3. Install dependencies:
   pip install -r requirements.txt
4. Add .env file with GROQ_API_KEY
5. Run:
   python app.py

## 🌍 Deployment

Deployed on Render
